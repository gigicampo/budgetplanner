Offline User Guide

Budget Planner

Set a monthly plan, record expenses in seconds, and review your progress without complicated formulas.

Return to Budget Planner

1. First-time setup

  1. Open the installed Budget Planner.
  2. Read the welcome guide, then select Start Planning.
  3. Choose Google Drive, Microsoft OneDrive, or Use offline for now.
  4. Approve the provider sign-in screen. The app creates a folder named Budget Planner.

The app asks you to connect cloud storage each time it opens. It never asks you to type a cloud password directly into Budget Planner.

2. Create a budget

  1. From Home, choose Budget Setup.
  2. Select the Budget Month and Year.
  3. Rename, add, or remove categories as needed.
  4. Select Annual, Monthly, or Daily frequency.
  5. Add each Item and its planned Amount.
  6. Press the check-mark Save button.

Use Duplicate Month Entry when a new month should reuse the same items and amounts.

3. Record an expense

  1. Choose New Expense. Today's date appears automatically.
  2. Enter Paid For and Amount.
  3. Select a Category and Item from the matching budget month.
  4. Press Save. A confirmation appears after a successful save.

Amounts must be greater than zero. Invalid dates, missing values, and duplicate rows are rejected with a specific red error message.

4. View and edit data

  • Open the Data page from Budget Setup or New Expense.
  • Select Edit Data, update the cells, and press Save Data.
  • Use Delete Rows to select and remove one or more records.
  • Use the download icon to save the latest Budget File.xlsx to the device.

5. Analytics and PDF reports

Analytics compares Budget and Expenses. A rose budget column means spending exceeded the planned amount.

  • By Month: compares all months in the selected year.
  • By Category: compares spending categories.
  • PDF: download the monthly report, category report, or both. The summary is included.

6. Offline use, backup, and recovery

The app keeps a protected offline copy on the current device. When the internet returns, queued changes synchronize after cloud sign-in.

  • Download an Excel backup regularly.
  • Do not clear browser or app storage before confirming a cloud sync or downloading a backup.
  • If cloud sync pauses, reconnect from the Cloud storage button.
  • If a PDF does not open, allow pop-ups and try again.

A downloaded file is the safest portable backup for device replacement or unexpected device failure.

7. Install on a device

  • Android/Chrome: open the menu and choose Install app or Add to Home screen.
  • iPhone/iPad/Safari: tap Share, then Add to Home Screen.
  • Desktop: use the Install icon in a supported browser.

Installation and cloud sign-in require the published HTTPS version of the app.
