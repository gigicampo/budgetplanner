Offline User Guide

Budget Planner

Plan a budget, track income and deductions, record expenses, and review your progress without complicated formulas.

Return to Budget Planner

1. Sign in or continue offline

  1. Open the installed Budget Planner.
  2. On the Login page, choose Continue with Google Drive or Continue Offline.
  3. Google credentials are entered only on Google's secure sign-in screen. The app reuses or creates one folder named Budget Planner.
  4. When asked What should we call you?, enter the name you want shown in the greeting. It is saved on that device.
  5. Read the welcome guide, then close it.

Your selected mode is remembered. Refreshing the site or installed app refreshes its content without showing the Login page again while the Google session remains valid. Offline mode remains selected on that device.

2. Create a budget

  1. From Home, choose Budget Setup.
  2. Select the Budget Month and Year.
  3. Rename, add, or remove categories as needed.
  4. Select Annual, Monthly, or Daily frequency.
  5. Add each Item and its planned Amount.
  6. Press the check-mark Save button. The entry rows reset after the data is secured.

Use Duplicate Month Entry when a new month should reuse the same items and amounts. Resetting the form does not remove saved rows from the Data Viewer, Analytics, or workbook.

3. Record income and deductions

  1. Choose My Income.
  2. Select the Income Month and Year.
  3. Use Salary, Business, or Part-Time, or add another category.
  4. Select Daily, Weekly, Bi-Monthly, or Monthly frequency and enter the gross Amount.
  5. Add deduction Items and Amounts. Net Income updates instantly as gross income or deductions change.
  6. Press Save. The entry fields reset after the data is secured; use the Data Viewer icon to review, edit, delete, or download saved rows.

Use Duplicate Income Month to copy categories, frequencies, gross amounts, and deductions into another month or year. In Excel, each deduction remains on its own row while shared category values are merged vertically.

4. Record an expense

  1. Choose New Expense. Today's date appears automatically.
  2. Enter Paid For and Amount.
  3. Select a Category and Item from the matching budget month.
  4. Press Save. A confirmation appears after a successful save.
  5. From the MyExpenses Data Viewer, choose Add / Edit Expense to return directly to New Expense; use Edit Data to change an existing saved row.

Amounts must be greater than zero. Invalid dates, missing values, and duplicate rows are rejected with a specific red error message.

5. View, edit, and import data

  • Open the Data page from Budget Setup, New Expense, or My Income.
  • Select Edit Data, update the cells, and press Save Data.
  • Use Delete Rows to select and remove one or more records.
  • Use the download icon or the Budget File.xlsx link on Home to save a genuine, editable Excel workbook with MyBudget, MyExpenses, and My Income worksheets.
  • After editing a local workbook, choose Import Budget File on Home. Review the Added, Changed, and Missing counts, then choose Merge or Replace.

Merge keeps current rows, adds missing imported rows, and applies imported values to matching records. Replace uses the imported workbook exactly.

6. Analytics and PDF reports

Analytics automatically refreshes after Budget, Expense, Income, imported, duplicated, deleted, or edited data is successfully saved. It compares Budget, Net Income, Expenses, and Available Balance. A rose budget column means spending exceeded the planned amount.

  • Report Month: leave All Months selected for the full year, or select one month.
  • By Month: compares monthly Budget, Expenses, and Net Income.
  • By Category: compares the available budget, expense, and income categories.
  • Landscape Home: rotating a tablet or larger phone to landscape shows the current-year graph above the navigation cards.
  • Print / Save Analytics as PDF: choose the monthly report, category report, or both. The summary and graphs are included.

7. Sync, logout, backup, and recovery

The app keeps an offline copy on the current device. Google Drive is loaded and validated before any refreshed content is uploaded. Local-only and cloud-only Budget, Expense, and Income rows are combined during reconnection to prevent saved values from disappearing.

  • Use Log out on Home to return to the Login page. Logging out disconnects Google Drive but does not delete saved budgeting data.
  • Download Budget File.xlsx regularly.
  • Do not clear browser or app storage before confirming a cloud sync or downloading a backup.
  • If the Google session expires, use Continue with Google Drive again; the existing workbook is reused.
  • If the print window does not open, allow pop-ups and try again.

Keep a recent downloaded workbook so it can be validated and imported if the device or browser data is lost.

8. Install on a device

  • Android/Chrome: open the menu and choose Install app or Add to Home screen.
  • iPhone/iPad/Safari: tap Share, then Add to Home Screen.
  • Desktop: use the Install icon in a supported browser.

Installation and cloud sign-in require the published HTTPS version of the app.
